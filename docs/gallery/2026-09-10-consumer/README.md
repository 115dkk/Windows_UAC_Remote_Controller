# 사용자 관점 문구와 첫 화면

Windows 첫 화면에서 앱의 목적을 먼저 설명하고, 일반 사용 화면의 서비스 표현을 휴대폰 승인과 사용자 행동으로 바꿨습니다. 켜짐과 실제 요청 전달 준비 상태는 구분합니다. 설치·제거, 자동 실행의 영향도 확인 창에서 설명합니다. IBM Plex Sans KR는 유지합니다.

웹 화면은 명시적인 합성 예시입니다. Windows/Linux CI의47개 사례와73개 PNG씩을 확인했고 ROOT가 대표 원본을 직접 검토했습니다. 200% 글자 크기에서는 탐색 메뉴와 본문을 각각 스크롤하며 한글 단어가 쪼개지지 않도록 보완했습니다.

Android 알림 이미지는 API36 에뮬레이터의 실제 SystemUI가 공유 알림 표시 코드를 그린 결과입니다. 별도 테스트 앱의 알림이며 실제 제품 서비스 시작·부팅·본인 인증·UAC 승인 증거가 아닙니다. 준비 완료 문구도 앱 설정에만 해당합니다.

모든 PNG는 CI 원본 그대로이며, 소스 커밋·크기·해시는 capture-manifest.json에 기록했습니다. 전체 제품과 프리릴리즈는 아직 미완료입니다.
