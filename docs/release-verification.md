# 릴리즈 검증 범위

이 문서는 해당 릴리즈 커밋의 검증 범위를 보존합니다. 릴리즈 본문의 링크는
변경되는 기본 브랜치가 아니라 정확한 빌드 커밋을 가리킵니다. 첨부되는
`release-verification.md`에는 버전, 빌드 커밋과 이전 공개 릴리즈도 기록합니다.
자동 검사 항목은 해당 커밋의 필수 CI가 통과하고 릴리즈가 실제 발행됐을 때의
범위이며, 소스 문서만으로 새 실행의 통과를 뜻하지 않습니다.

## 과거 결과와 이번 설치본의 사용자 시험

직접 연결 확장은 PC의 내장 중계를 유지합니다. PC가 휴대폰에 알리는 외부 주소는
세 가지 방법으로 얻습니다. 자동 모드는 공유기에 PCP로, 응답이 없으면 UPnP로 포트
매핑을 요청합니다. UPnP 매핑은 먼저 그 포트의 기존 항목을 읽어, 다른 기기나 다른
내부 포트의 항목이면 덮어쓰지 않고 다른 포트를 고릅니다. 사용자가 공유기에서
포트포워딩이나 DMZ를 직접 설정한 경우에는 STUN 서버(Google, Cloudflare)에 이 집의
공인 IPv4를 묻고, 외부 주소를 직접 입력한 경우에는 그 값을 그대로 씁니다. 어느
방법으로 얻은 주소든 접속 후보이며 외부망 연결 성공을 뜻하지 않습니다. NAT-PMP는
쓰지 않습니다. 사용자의 클라우드 계정이나 중계 할당량을 사용하지 않습니다.

주소 질의·서명·세대별 캐시·이전 저장 형식 마이그레이션, PCP 임대와 UPnP 매핑,
STUN 응답 해석은 CI의 프로토콜 및 루프백 시험 대상입니다. 실제 공유기의 PCP·UPnP
지원, 외부망에서 PC까지 연결되는지, 공인 주소가 바뀐 뒤 기존 경로가 모두 끊겼을
때의 복구, 실제 휴대폰 인증 지연은 별도 실기 확인 대상입니다. 방화벽의 연결 허용 알림은
표시된 프로그램이 UAC 원격 승인기 서비스인지 확인한 뒤 사용자가 판단합니다.

기존 설치본의 휴대폰 본인 확인과 Windows UAC 승인 수락은 사용자 시험으로
확인됐습니다. alpha.40은 실제 휴대폰에서 승인 세션 정리 다섯 건을 확인했고,
각 진입 충돌은 50ms 뒤 재시도하여 정리됐습니다. 다섯 건의 Windows 최종
결과를 모두 대조한 것은 아닙니다. 과거 기록은
[alpha.40](https://github.com/115dkk/Windows_UAC_Remote_Controller/releases/tag/v0.1.0-alpha.40)에서 확인할 수 있습니다.

재부팅 후 서비스가 중지되던 증상은 원인을 끝까지 좁히지 못한 채 완화 조치만 들어갔습니다.
2026-09-15부터 09-22까지 네 번의 콜드 부팅이 모두 같은 코드로 실패했고, 같은 등록·같은
계정으로 수동 시작은 성공했습니다. 제품이 남긴 진단은 실패 지점을 등록 구성 검증까지
좁혔지만, 그 안의 어느 항목이 거부하는지는 아직 확정되지 않았습니다.

이번 판은 세 가지를 넣었습니다. 첫째, 자동 시작이 한 번 실패해도 Windows가 5초와 30초
뒤에 다시 시작하도록 SCM 복구 계약을 설치 시점에 적용합니다. 재시작할 때마다 기존의
모든 시작 검증을 처음부터 다시 수행하므로 승인 기준은 넓어지지 않습니다. 둘째, 등록된
실행 경로를 Windows가 경로를 비교하는 방식으로 비교합니다. 따옴표 모양과 고정 인자는
그대로 완전 일치를 요구합니다. 셋째, 실패 지점을 한 칸이 아니라 항목별로 기록합니다.

복구 계약은 중단 시간을 짧게 만들 뿐 첫 시도를 성공시키지 않습니다. 첫 시도가 이제
성공하는지, 어느 항목이 거부했는지는 다음 콜드 부팅의 실제 기록으로만 확인됩니다.
이 판을 그 확인이 끝난 것으로 읽어서는 안 됩니다.

실제 기기별 USB 연결, 이번 Windows 설치본의 재부팅 동작, 새 설치본의 전체
승인 여정과 휴대폰 본인 확인은 별도 사용자 시험 항목입니다. 정식 버전 표기는
이 범위를 확대하지 않습니다. 실제 UAC 승인과 휴대폰 인증의 새 시험 결과가
제공되기 전까지 이 버전에 대한 실기 검증으로 간주하지 않습니다.

## 설치 화면과 진단 기록

설치 막대의 자동 검증은 제품과 같은 NSIS/MUI 배치 함수를 쓰는 무해한 테스트
화면과 큰 글자 조건을 포함하며, 모든 실제 모니터 DPI 조합을 검증한 것은 아닙니다.

일반 권한에서 [로그 폴더 열기]로 탐색기가 열리는지는 사용자 동의에 따라
설치 후 확인합니다. 기존 CI 실행기의 탐색기가 관리자 권한으로 실행되어
이 검증을 수행하지 못했습니다. 일반 사용자의 로그 읽기 허용·쓰기 차단,
비공개 저널 접근 차단과 나머지 보안·페어링 검사는 유지합니다.

공개 진단 기록은 `%ProgramData%\UACRemoteController-Logs\diagnostics.jsonl`에
저장되며, 일반 사용자는 읽거나 복사할 수 있습니다. 공개 진단 파일에는
처리 결과·실패 코드·시간·프로세스 ID만 남깁니다. 요청 본문, 프로그램 이름,
전체 명령줄, 기기 식별자, 키·인증 정보는 포함하지 않습니다. 보호된 원본
저널과 등록 정보의 접근 권한은 유지합니다. 최대 1MiB를 넘으면 새 기록부터
저장하며, 로그 쓰기 실패는 승인 판단이나 서비스 실행 상태를 변경하지 않습니다.

Android 활동 기록에서 내보낸 제한된 진단 로그는 `Downloads/UAC Remote Approval`에
저장됩니다. 공유 대상을 고르는 주체는 사용자이며 앱이 업로드하지 않습니다.

별도의 `진단 로그 파일로 저장`은 Android 파일 선택기에서 고른 위치에 저장하고
공유 화면은 열지 않습니다. API36 에뮬레이터에서 실제 선택기 취소와 문서 제공자의
파일 읽기 검사를 수행합니다. 이 검사는 실제 휴대폰·모든 저장소 제공자·JavaScript
브리지 전체 여정의 증거를 대신하지 않습니다.
