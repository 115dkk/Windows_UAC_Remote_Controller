# UAC 원격 승인 {{VERSION}} 프리릴리즈

## 이번 변경

- PC 연결 준비에서 실행 파일의 네이티브 경로를 보유 중인 설치 파일과 매번 대조하도록 변경했습니다. 기존 파일 권한·파일 신원·프로세스 검사는 유지합니다.
- QR 표시 프로세스의 창 스테이션 검사에는 실제 사용하는 속성 조회 권한만 요청합니다. 실패 기록은 데스크톱과 창 스테이션 전달을 구분합니다.
- QR 화면의 독립 검사를 서비스가 만든 사용자 세션 내 검사 프로세스에서 수행하도록 변경했습니다. 연결 결정까지 화면 객체를 유지·재검사하며 기존 서비스의 프로세스·파일·토큰 검증도 유지합니다.
- QR 내용을 전달하기 전에 숨은 검증용 창이 원래 프로세스·스레드와 보호된 데스크톱에 속하는지 Windows에서 확인합니다. 확인용 창은 통신 종료까지 유지하며 기존 제한 권한을 사용합니다.
- Android CI에서 강제 종료 후 저장소를 다시 열지 못한 실행이 있었습니다. 이후 수명주기 시험은 통과했으며, 원인이 확정되지 않은 실패를 구분할 진단을 추가했습니다.
- Windows CI가 실제 PC 앱에서 관리자 확인을 거쳐 QR을 열고, 별도 소프트웨어 휴대폰 픽스처가 화면의 QR을 읽어 연결하도록 시험을 확장했습니다.
- 양쪽 비교 확인, 서비스의 기기 등록, 실제 UAC 요청 전달, 같은 요청에 대한 서명된 거절 응답과 Windows 취소 결과를 모두 검사합니다. 시험 대상 프로그램이 실행되면 실패합니다.
- 이 연결 시험과 Android 릴리스 시작 시험이 해당 커밋에서 통과해야 프리릴리즈가 발행됩니다. 소프트웨어 픽스처는 실제 Android 하드웨어 인증이나 생체 인증을 대신하지 않습니다.
- Windows 연결 실패 단계와 원래 오류 코드를 제한된 진단 기록에 남깁니다. QR·비교 숫자·키·자격 증명은 기록하지 않습니다.
- 아래 항목은 이전 프리릴리즈의 변경 사항으로 계속 포함됩니다.

- QR 준비가 시작된 뒤에는 상태 새로고침이 같은 통신 자리를 먼저 차지하지 않도록 요청 순서를 조정했습니다.
- 이전 연결 작업이 실제로 종료되기 전에는 새 연결을 시작하지 않습니다. 오류 문구의 표시 시간이 끝나도 정리 중인 작업은 유지합니다.
- 작업 종료 확인이 실패했거나 종료 결과가 누락됐을 때, 다음 조회에서 성공 또는 진행 중 상태로 되돌아가던 처리를 수정했습니다.
- 이전 Windows CI는 실제 앱의 QR 버튼에서 Windows 승인 창까지 확인한 뒤 취소하는 범위였습니다. 이번 판부터 승인 후 QR 표시와 소프트웨어 픽스처의 연결·거절까지 검사합니다. 실제 휴대폰 등록과 원격 승인은 별도 사용자 시험 항목입니다.

- Windows 관리 앱이 서비스의 신원과 생존 여부를 확인할 때 필요한 프로세스 조회 권한을 서비스 시작 과정에서 설정합니다. 일반 사용자에게는 제한된 정보 조회와 종료 확인만 허용하며, 메모리 읽기·프로세스 제어 권한은 주지 않습니다.

- 설치 시 바탕화면·시작 메뉴·작업표시줄 선택을 받습니다. 새 설치는 선택, 업그레이드·복구는 선택 해제가 기본값이며 기존 바로가기는 유지합니다.
- 작업표시줄 고정은 설치 후 앱에서 Windows 확인을 거칩니다. 지원하지 않는 Windows에는 직접 고정하는 방법을 안내합니다.
- 내장 중계의 방화벽 허용은 해당 서비스·실행 파일의 TCP 7443, 개인 네트워크 프로필로 한정합니다. 외부 모바일망에는 PC에 도달하는 경로나 외부 중계가 필요합니다.

- Windows TPM 키의 생성 중 속성과 완성된 속성을 구분해 초기화를 검사합니다.
- TPM이 생성 중 반환하는 `ECDSA`, 길이 `0`, 키 종류 `0` 때문에 발생한 `0xE1000009` 거부를 수정합니다.
- 완성된 키의 256비트·컴퓨터 범위·TPM 제공자·접근 권한·서명 전용·비공개 키 내보내기 금지 검사는 유지합니다.
- 알고리즘 이름뿐 아니라 실제 P-256 공개키 형식과 곡선도 검사합니다.
- 이전 판의 Android QR 진입·알림 설정 수정은 유지됩니다.
- 기존 연결·인증 조건과 저장된 설정·기기 정보는 유지합니다.

이 판은 시험용 프리릴리즈입니다. 설치 파일과 APK를 만들었을 뿐, 실제 PC와 휴대폰에서
원격 승인이 동작했다는 증거는 아닙니다. 아래 표의 각 항목은 이 판에서 실제로 어디까지
검증했는지를 적은 것입니다.

## 시작하기

1. Windows에 설치 파일을 실행하고 관리자 확인을 승인합니다. 설치가 끝나면 서비스가 부팅 때
   자동으로 시작되도록 등록됩니다.
2. 같은 네트워크에 PC와 휴대폰을 연결합니다. Windows의 네트워크 프로필은 ‘개인’이어야 합니다.
   내장 중계는 서비스와 함께 준비됩니다. 이전에 외부 중계를 설정했다면 앱의 [휴대폰 관리]에서 [이 PC의 내장 중계 사용]을 선택합니다.
3. 외부 모바일망으로 연결하려면 PC로 들어오는 연결 경로나 공개 주소의 외부 중계가 필요합니다.
   외부 중계 주소는 앱의 [고급 설정: 외부 중계 서버]에서 입력할 수 있습니다.
4. 휴대폰에 APK를 설치하고 화면 잠금(PIN, 패턴, 비밀번호, 생체)을 설정합니다.
5. PC의 UAC 원격 승인 앱에서 [휴대폰 관리] → [UAC 원격 승인]을 누르면 관리자 확인 뒤 QR이 보호된 화면에 표시됩니다.
   휴대폰 앱에서 [PC의 QR 코드 촬영]으로 QR을 읽고, 양쪽에 표시된 여섯 자리 숫자가 같은지 확인한 뒤
   양쪽에서 확인을 누릅니다.
