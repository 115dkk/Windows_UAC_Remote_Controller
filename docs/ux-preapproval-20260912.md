## 구현·권한 범위

QR 버튼은 기존 기기 등록 절차의 진입점이다. 실제 UAC 요청을 승인하는 버튼이
아니다. PC에서는 기존 관리자 확인 절차를 거치며, 네이티브 연결 기능과 중계
서버 설정이 준비되기 전에는 실행하지 않는다. 휴대폰의 스캐너도 네이티브
capability를 그대로 따른다. 새 인증·서명·입력 주입 API는 추가하지 않았다.

Windows 표시 이름은 바뀌지만 `dev.dkk115.uacremote`, 서비스 ID, 기존 보호된
설치 폴더와 설정·기기 정보·레지스트리 식별자는 유지한다. 기존 이름의 바로가기는
고정 앱 실행 파일을 가리킬 때만 새 이름으로 옮긴다. 대상 이름 충돌 시 덮어쓰지
않고 중단한다. `/NOSHORTCUTS`는 이름 변경을 생략하며, 제거 시 이전 이름도
대상을 확인한 뒤 처리한다. 이 변경에서 설치 프로그램은 실행하지 않았다.

로고 원본: `src-tauri/icons/source.svg` (GPL-2.0-or-later).
재생성: `npm run icons:generate`. 기존 벡터 원본을 수정하고 Tauri 아이콘 컴파일러로
각 플랫폼 크기를 생성했다. 생성형 이미지나 외부 이미지 서비스는 사용하지 않았다.
Android 적응형 아이콘은 16% 여백으로 주요 도형의 잘림을 줄였다.

## 검증 상태

- ROOT UI 테스트 92개 통과, TypeScript·ESLint·프로덕션 빌드 통과.
- 브랜딩·소비자 문구·Windows 패키징 소스 검사 36개 통과.
- ROOT Rust fmt, Clippy `-D warnings`, 실제 Rust Analyzer 진단 통과.
- Android SDK aapt2로 실제 리소스 컴파일 통과. APK 설치나 런처 실기기 검증은 아님.
- 정적 보안 검토에서 발견한 기존 이름 바로가기 문제를 수정하고 재검토했다.
- ROOT가 새 PC QR 활성/비활성 화면, Android 미연결 화면, 자체 아이콘 PNG를 열어 검토했다.

자동 갤러리는 호스트 AdGuard 삽입 요청·헤더 경고로 실패했다. 외부 요청 차단이나
콘솔 검사 기준은 유지했으며, 깨끗한 CI 환경에서 재검증해야 한다. 최초 전체
갤러리의 PC 672px 사례에는 별도의 CSS 요청 `ERR_NO_BUFFER_SPACE` 실패도 있었다.
이 화면 캡처는 클라이언트 합성 상태이며 실제 Windows/Android 연결 증거가 아니다.

새 설치본 빌드·업데이트 시험·휴대폰 설치, 실제 QR 기기 등록·휴대폰 본인 확인·UAC
승인은 아직 수행하지 않았다. 이 문서는 전체 제품 완료나 배포를 뜻하지 않는다.
