## 이번 변경

- PC에서 QR이 갑자기 화면 전체를 덮던 방식을 바꿨습니다. 이제 무엇을 하는 절차인지, 휴대폰에서 무엇을 먼저 켜야 하는지, 어떻게 중지하는지를 먼저 안내하는 화면이 나오고, [QR 코드 보기]를 눌러야 QR이 보입니다.
- 안내 화면에 주의 문구를 넣었습니다. 다른 사람의 요청으로 이 절차에 들어왔다면 바로 중지하라는 내용과, QR 코드를 다른 사람에게 공유하지 말라는 내용입니다.
- QR 화면에서 나갈 수 없던 문제를 해결했습니다. [취소하고 돌아가기] 단추를 넣었고, ESC 키도 받습니다. 두 화면 모두에서 언제든 원래 화면으로 돌아갑니다. 비교 숫자가 나오기 전에 나가는 것은 아무것도 결정하지 않으며, 키나 등록을 만들지 않습니다.
- 남은 시간 표시를 '01:47 후 종료' 형태로 바꿨습니다. 남은 시간을 세는 대신 언제 끝나는지만 알립니다. 화면이 알아서 닫힌다는 안내는 통제권이 사용자에게 없다는 뜻으로 읽혀 넣지 않았습니다.
- 번역이 긴 언어에서 글자가 잘리던 문제를 함께 고쳤습니다. 비교 숫자 화면의 단추를 가장 긴 번역에 맞춰 키웠고, 왼쪽 위 이름이 카드에 가릴 만큼 길면 잘라서 보여주는 대신 표시를 생략합니다.
- 화면 왼쪽 위에 프로그램 표시와 이름을 한 번만 넣었습니다. QR 자체의 크기와 선명도는 바꾸지 않았습니다. 휴대폰 카메라와 CI 검사가 읽는 최소 크기를 화면 크기별로 지키는지 시험으로 확인합니다.
- 휴대폰에서 QR을 찍어 연결하는 도중 앱이 갑자기 종료되던 문제를 수정했습니다. 연결 절차가 키 생성을 요청하고, 그 안에서 시간 확인이 다시 들어오는 순간 해당 작업 스레드가 실행 중에 분리되어 Android가 앱을 종료했습니다. 이제 그 스레드를 연결이 끝날 때까지 유지합니다.
- 연결이 중단된 뒤 앱이 다시는 열리지 않던 문제를 수정했습니다. 저장이 중간에 끊겨 남은 기록은 내용을 확인한 뒤에만 정리하고, 마지막으로 확정된 상태를 그대로 엽니다. 확정된 저장 파일은 다시 쓰거나 새로 만들지 않으며, 알 수 없는 파일이 남아 있으면 정리하지 않고 멈춥니다.
- 키를 만들다 중단되어 남은 준비 기록 때문에 앱이 열리지 않던 문제를 수정했습니다. 그 준비에 해당하는 키만 지운 뒤 기록을 철회하며, 등록을 마친 키와 그 밖의 기록은 지우지 않습니다. 지우기가 끝나기 전에는 기록을 철회하지 않으므로 중단되면 다음 실행에서 다시 시도합니다.
- 앱 준비에 실패했을 때 최신 버전으로 업데이트하라고 안내하던 문구를 바꿨습니다. 업데이트로는 해결되지 않는 상황이므로, 앱을 완전히 닫았다가 다시 열도록 안내합니다.

검증했는지를 적은 것입니다.

## 내려받기

| 파일 | 용도 |
| --- | --- |
| `uac-remote-controller-windows-x64-setup.exe` | Windows 11 x64 설치 파일. 설치 때 관리자 확인이 한 번 필요합니다. |
| `uac-remote-controller-android-arm64.apk` | Android 11(API 30) 이상, arm64 휴대폰용 앱. |
| `uac-relay-windows-x64.exe`, `uac-relay-linux-x64` | 선택 사항인 외부 서버용 중계입니다. PC 내장 중계를 쓸 때는 별도로 실행하지 않습니다. |
| `SHA256SUMS.txt` | 위 파일들의 SHA-256. |

## 서명

- Android APK 서명 인증서 SHA-256: `{{SIGNER_SHA256}}` (출처: {{SIGNER_SOURCE}})
- Windows 설치 파일과 실행 파일은 코드 서명이 없습니다. SmartScreen 경고가 표시됩니다.

`ephemeral-this-run-only`라고 적혀 있으면 이 판을 만들 때 임시로 만든 서명 키입니다. 다음 판은
다른 키로 서명되므로 그대로 덮어 설치할 수 없고, 앱을 지운 뒤 설치해야 합니다.

## 시작하기

1. Windows에 설치 파일을 실행하고 관리자 확인을 승인합니다. 설치가 끝나면 서비스가 부팅 때
   자동으로 시작되도록 등록됩니다.
2. 같은 네트워크에 PC와 휴대폰을 연결합니다. Windows의 네트워크 프로필은 ‘개인’이어야 합니다.
   내장 중계는 서비스와 함께 준비됩니다. 이전에 외부 중계를 설정했다면 앱의 [휴대폰 관리]에서 [이 PC의 내장 중계 사용]을 선택합니다.
3. 외부 모바일망으로 연결하려면 PC로 들어오는 연결 경로나 공개 주소의 외부 중계가 필요합니다.
   외부 중계 주소는 앱의 [고급 설정: 외부 중계 서버]에서 입력할 수 있습니다.
4. 휴대폰에 APK를 설치하고 화면 잠금(PIN, 패턴, 비밀번호, 생체)을 설정합니다.
5. PC의 UAC 원격 승인 앱에서 [휴대폰 관리] → [UAC 원격 승인]을 누르면 관리자 확인 뒤 QR이 보호된 화면에 표시됩니다.
   휴대폰 앱에서 [PC의 QR 코드 촬영]으로 QR을 읽고, 양쪽에 표시된 여섯 자리 숫자가 같은지 확인한 뒤
   양쪽에서 확인을 누릅니다.
