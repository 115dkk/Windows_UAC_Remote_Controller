## 이번 변경

- PC 진단 기록을 GUI 실행 여부와 관계없이 `%ProgramData%\UACRemoteController-Logs\diagnostics.jsonl`에 저장합니다. 일반 사용자는 읽거나 복사할 수 있으며, 앱의 활동 기록 화면에서 [로그 폴더 열기]로 접근할 수 있습니다.
- 공개 진단 파일에는 처리 결과·실패 코드·시간·프로세스 ID만 남깁니다. 요청 본문, 프로그램 이름, 전체 명령줄, 기기 식별자, 키·인증 정보는 포함하지 않습니다. 보호된 원본 저널과 등록 정보의 접근 권한은 유지합니다.
- 진단 파일은 최대 1MiB이며, 다음 기록이 한도를 넘으면 새 기록부터 다시 저장합니다. 로그 쓰기 실패는 승인 판단이나 서비스 실행 상태를 변경하지 않습니다.
- 설치 진행 막대가 창 오른쪽을 넘어가는 현상을 수정했습니다. 실제 창과 컨트롤 크기를 사용해 설치 시작·완료 시 폭을 맞춥니다. 설치 창에 표시되던 불필요한 `Null` 문구도 제거했습니다.
- `main` 반영 시 정식 릴리즈를 자동으로 시작합니다. 첫 버전은 `1.0.0`이며, 이후 변경 기록의 호환성 파괴는 major, 기능 추가는 minor, 나머지는 patch로 올립니다. 버전이 반영된 커밋의 검증을 모두 통과한 뒤 새 태그를 만들며, 공개된 태그와 파일은 덮어쓰지 않습니다.
- 정식 Android APK에는 기존 영구 서명키를 사용합니다. 키가 없거나 서명 지문이 달라지면 발행을 중단합니다.

## 기존 기능과 확인 범위

Windows UAC 요청을 연결된 Android 휴대폰에서 승인하거나 거부합니다. QR과 USB는 같은 등록 절차의 입력 경로이며, 비교 코드와 양쪽 확인을 거칩니다. USB는 AOA 지원 기기와 호환 WinUSB 드라이버가 필요합니다.

기존 설치본의 휴대폰 본인 확인과 Windows UAC 승인 수락은 사용자 시험으로 확인됐습니다. alpha.40은 실제 휴대폰에서 승인 세션 정리 다섯 건을 확인했고, 각 진입 충돌은 50ms 뒤 재시도하여 정리됐습니다. 다섯 건의 Windows 최종 결과를 모두 대조한 것은 아닙니다.

실제 기기별 USB 연결, 이번 Windows 설치본의 재부팅 동작, 새 설치본의 전체 승인 여정은 별도 실기 확인 항목입니다. 정식 버전 표기는 이 범위를 확대하지 않습니다. 설치 막대의 자동 검증은 제품과 같은 NSIS/MUI 배치 함수를 쓰는 무해한 테스트 화면과 큰 글자 조건을 포함하며, 모든 실제 모니터 DPI 조합을 검증한 것은 아닙니다.

이전 변경 기록: [alpha.40](https://github.com/115dkk/Windows_UAC_Remote_Controller/releases/tag/v0.1.0-alpha.40).

## 설치

1. Windows 설치 파일을 실행하고 관리자 확인을 승인합니다.
2. Android APK는 기존 앱 위에 업데이트합니다. 앱 데이터를 지우거나 삭제한 뒤 설치할 필요는 없습니다.
3. 새 연결은 PC의 [휴대폰 관리]와 휴대폰의 [연결된 PC]에서 QR 또는 USB로 진행합니다.
4. 같은 네트워크에서는 PC의 내장 중계를 사용합니다. 외부 모바일망은 PC로 들어오는 경로나 별도 외부 중계가 필요합니다.
