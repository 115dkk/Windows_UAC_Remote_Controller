# Bundled multilingual fonts

Unmodified Google Fonts sources pinned at commit
`809e4d8b8d7e9364a914909bb777679606c178b8` in https://github.com/google/fonts.

- `ofl/notosans/NotoSans[wdth,wght].ttf`
- `ofl/notosansarabic/NotoSansArabic[wdth,wght].ttf`
- `ofl/notosansjp/NotoSansJP[wght].ttf`
- `ofl/notosanssc/NotoSansSC[wght].ttf`
- `ofl/notosanstc/NotoSansTC[wght].ttf`

Each adjacent `*-OFL.txt` preserves the corresponding copyright and license.
They are bundled UI assets, not remotely loaded fonts. Korean retains the
separate existing IBM Plex Sans KR font pack. Native GDI faces are generated by
`tools/prepare-native-fonts.py` with fontTools4.63.0 and Brotli1.2.0, retaining full
glyph coverage and OFL but renamed `UAC Sans*` to distinguish derivatives.
Their hashes and source paths are in `assets/fonts/native/manifest.json`.
