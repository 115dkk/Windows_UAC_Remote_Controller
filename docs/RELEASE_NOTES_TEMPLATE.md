# UAC 원격 승인 {{VERSION}} 프리릴리즈

## 이번 변경

- [다시 확인]과 언어 설정 버튼을 제목 줄 끝에 배치했습니다. 설명문이 길어지거나 탭을 바꿔도 버튼이 아래 줄로 밀리지 않습니다.
- 좁은 화면과 큰 글자에서는 새로고침을 아이콘으로 표시하며, 접근성 이름과 누르기 영역은 유지합니다. 설명문은 별도 줄 전체 너비를 사용합니다.
- 아래 항목은 이전 프리릴리즈의 변경 사항으로 계속 포함됩니다.

- 한국어에 영어·프랑스어·독일어·일본어·중국어(간체/번체)·스페인어·포르투갈어(브라질/포르투갈)·아랍어를 추가했습니다.
- 첫 실행은 시스템 언어를 따릅니다. 화면 위쪽의 [앱 설정]에서 언어를 바꾸거나 시스템 언어로 돌아갈 수 있습니다. 지원하지 않는 언어는 영어로 표시합니다.
- 앱 화면과 자체 제작한 네이티브 연결 화면에 언어별 글꼴을 포함했습니다. Windows UAC와 Android 본인 확인 등 운영체제 소유 화면은 운영체제 설정을 따릅니다.
- 프로그램·경로·명령행의 숨은 방향 제어 문자를 `[U+202E]`처럼 표시하고, 주변 아랍어 문장과 방향을 분리합니다. 서명과 다이제스트에 사용하는 원본 요청은 변경하지 않습니다.
- Android 알림에서 이름이나 경로가 생략되거나 표시 길이를 넘으면 상세 화면에서 확인하도록 안내합니다.
- 아래 항목은 이전 프리릴리즈의 수정 사항으로 계속 포함됩니다.

- Windows 백그라운드 서비스에 중계를 포함했습니다. 별도 중계 프로그램 없이 같은 네트워크에서 연결을 준비하며, 앱 창을 닫아도 서비스와 함께 실행됩니다.
- 설치 시 바탕화면·시작 메뉴·작업표시줄 선택을 받습니다. 새 설치는 선택, 업그레이드·복구는 선택 해제가 기본값이며 기존 바로가기는 유지합니다.
- 작업표시줄 고정은 설치 후 앱에서 Windows 확인을 거칩니다. 지원하지 않는 Windows에는 직접 고정하는 방법을 안내합니다.
- 내장 중계의 방화벽 허용은 해당 서비스·실행 파일의 TCP 7443, 개인 네트워크 프로필로 한정합니다. 외부 모바일망에는 PC에 도달하는 경로나 외부 중계가 필요합니다.
- 키 생성 확정 후 저장된 키를 다시 열어 검증하고, 이 핸들을 실제 실행에 사용합니다.
- 검증 실패 때 키 삭제를 시도하던 처리를 없애 키와 최초 오류를 보존합니다.
- 관리자 재설치에서 연결 정보 파일이 완전히 없는 중단 상태만 한 번 이어서 초기화할 수 있게 합니다. 기존 연결 정보 파일은 빈 파일이나 손상된 파일도 덮어쓰지 않습니다.
- Windows TPM 키의 생성 중 속성과 완성된 속성을 구분해 초기화를 검사합니다.
- TPM이 생성 중 반환하는 `ECDSA`, 길이 `0`, 키 종류 `0` 때문에 발생한 `0xE1000009` 거부를 수정합니다.
- 완성된 키의 256비트·컴퓨터 범위·TPM 제공자·접근 권한·서명 전용·비공개 키 내보내기 금지 검사는 유지합니다.
- 알고리즘 이름뿐 아니라 실제 P-256 공개키 형식과 곡선도 검사합니다.
- 이전 판의 Android QR 진입·알림 설정 수정은 유지됩니다.
- 기존 연결·인증 조건과 저장된 설정·기기 정보는 유지합니다.

이 판은 시험용 프리릴리즈입니다. 설치 파일과 APK를 만들었을 뿐, 실제 PC와 휴대폰에서
원격 승인이 동작했다는 증거는 아닙니다. 아래 표의 각 항목은 이 판에서 실제로 어디까지
검증했는지를 적은 것입니다.

## 시작하기

1. Windows에 설치 파일을 실행하고 관리자 확인을 승인합니다. 설치가 끝나면 서비스가 부팅 때
   자동으로 시작되도록 등록됩니다.
2. 같은 네트워크에 PC와 휴대폰을 연결합니다. Windows의 네트워크 프로필은 ‘개인’이어야 합니다.
   내장 중계는 서비스와 함께 준비됩니다. 이전에 외부 중계를 설정했다면 앱의 [휴대폰 관리]에서 [이 PC의 내장 중계 사용]을 선택합니다.
3. 외부 모바일망으로 연결하려면 PC로 들어오는 연결 경로나 공개 주소의 외부 중계가 필요합니다.
   외부 중계 주소는 앱의 [고급 설정: 외부 중계 서버]에서 입력할 수 있습니다.
4. 휴대폰에 APK를 설치하고 화면 잠금(PIN, 패턴, 비밀번호, 생체)을 설정합니다.
5. PC의 UAC 원격 승인 앱에서 [휴대폰 관리] → [UAC 원격 승인]을 누르면 관리자 확인 뒤 QR이 보호된 화면에 표시됩니다.
   휴대폰 앱에서 [PC의 QR 코드 촬영]으로 QR을 읽고, 양쪽에 표시된 여섯 자리 숫자가 같은지 확인한 뒤
   양쪽에서 확인을 누릅니다.
